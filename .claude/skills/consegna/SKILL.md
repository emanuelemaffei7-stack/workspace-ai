---
name: consegna
description: Check that the weekly mini game is ready to hand in. Use when the student says "consegna", "ho finito", "è pronto?".
---

Check the mini game in `gioco/` before it is handed in, and report in Italian as a short checklist.

1. `gioco/index.html` opens and the game starts with no errors (read the code for obvious errors; if Node is available, check the script syntax).
2. There is a way to win or a score, and a way to lose.
3. `gioco/GDD.md` exists and matches what was built.
4. `gioco/README.md` exists with: name of the student, how to play, what they wrote themselves, what the AI wrote, one thing they learned. If it is missing, interview them and write it with **their** words.
5. Ask the student to explain one function of the game in their own words. If they cannot, go back to it with `/spiega` before handing in.

Do not add features at this stage.
