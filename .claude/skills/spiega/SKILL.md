---
name: spiega
description: Explain a file or a piece of code line by line to a beginner. Use when the student says "spiega", "spiegami", "cosa fa questo codice", or asks about a specific function.
---

Explain the code the student points to (default: `gioco/index.html`) in Italian, for someone who started programming a few weeks ago.

1. First the big picture in 2 or 3 sentences: what this code does in the game.
2. Then block by block, quoting a few lines at a time, and naming the course concept each block uses: variabile, condizione, ciclo, funzione, evento.
3. One everyday analogy where it helps.
4. Close with **one question** that checks they understood, and a tiny change they can try themselves to see the effect.

Do not modify any file.
