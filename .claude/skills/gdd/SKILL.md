name: gdd
description: Write a one page game design document with the student before any code. Use when they say "gdd", "idea", "progettiamo il gioco", or start a new game.
---

Help the student write a **one page game design document** in Italian, saved as `gioco/GDD.md`.

1. Ask the questions **one at a time**, waiting for each answer: genre, protagonist, goal, how you win, how you lose, the main enemy or obstacle, controls.
2. If they are stuck, offer 3 short options, never decide for them.
3. Keep the scope tiny: a game that can be built in one afternoon. If the idea is too big, say so and help them cut it.
4. Write `gioco/GDD.md` with these sections: Titolo, In una frase, Come si gioca, Si vince se, Si perde se, Controlli, Prima versione (the 3 features to build first).
5. End by proposing the first small step to build.
